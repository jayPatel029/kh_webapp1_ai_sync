# Archived legacy documentation

These files are retained for historical context and implementation provenance,
but are no longer primary entry points. Start with the canonical documentation
listed in [`../README.md`](../../README.md).

The archive contains duplicate deep dives, historical completion/refactoring
reports, one-off integration prompts, and superseded quick guides. Detailed API
references, design-system references, and P2–P4 clinical specifications remain
outside this directory because they are still useful source material.
