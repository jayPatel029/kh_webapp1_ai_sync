## Step 2: Redesign Stock Page "Add Stock" Flow

**File:** `src/pages/dialysis/DialysisInventory.jsx`

### 2a: Replace stock modal "add" mode with Restock Request flow

The "Add Stock" button on the Stock tab currently opens a dual-mode modal (`stockModalMode: 'add' | 'issue'`).
Change the button to say **"Request Restock"** and remove the "Issue Stock" button (keep issue as a separate inline action or remove if not needed).

**New flow when "Request Restock" is clicked:**
1. Open a **Restock Request Modal** that collects:
   - Supplier selection (dropdown from `suppliers` state)
   - List of items with quantity (reuse existing multi-item row pattern)
2. On submit, call `createRestockRequest({ items, organization_id: 1, clinic_id: 1 })`
3. On success, the response includes `po_id` — immediately open the **PO Finalization Modal** (`isPoModalOpen`) pre-filled with `po_id`
4. In PO Finalization Modal, user selects supplier (again or confirm), sets expected delivery date, and clicks "Finalize"
5. On PO Finalize submit, call `updateProcurementOrder(po_id, { supplier_id, expected_delivery_date, status: 'PENDING' })`
6. On success, refresh PO list, refresh Deliveries list, show toast

### 2b: Remove the "issue" mode from stock modal

Remove `stockModalMode`, `openStockModal(mode)`, and the conditional rendering inside the stock FormModal.
Replace with a single "Request Restock" flow as described above.

### 2c: Keep the stock "Issue Stock" as a separate action

If issuing stock is still needed, add an "Issue" button per row in the stock table (via actions column) rather than a global modal, OR keep a simple "Issue Stock" button that opens a simplified modal only for issuing (not restocking).

  const colors = {
    COMPLETED: { bg: '#DCFCE7', text: '#166534' },
    PARTIAL: { bg: '#DBEAFE', text: '#1E40AF' },
    PENDING: { bg: '#FEF9C3', text: '#854D0E' },
    ORDER_PLACED: { bg: '#DBEAFE', text: '#1E40AF' },

  return <span style={{ background: c.bg, color: c.text, padding: '3px 10px', borderRadius: '9999px', fontSize: '12px', fontWeight: 600 }}>{v}</span>;
}

## Summary of User Flow (After Changes)

1. **Stock tab** → Click "Request Restock"
2. **Restock Modal** → Select supplier, add items + quantities → Submit
3. **PO Finalization Modal** → Confirm supplier, set expected delivery date → Finalize
4. **Procurement tab → PO sub-tab** → See newly created PO with status ORDER_PLACED → PENDING after finalization
5. **Procurement tab → Delivery sub-tab** → When delivery arrives, click "Validate"
6. **Delivery Validation Modal** → Enter invoice, payment, verify received quantities per item → Submit
7. Stock is now updated and available for issuing
